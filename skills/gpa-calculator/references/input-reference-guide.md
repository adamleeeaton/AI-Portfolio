# Identifying input values

Customize this guide for `[institution name]`.

- Authorized `[advisor or staff role]` may use `[approved academic-history report]`.
- Use `[approved reporting point]` for the cumulative GPA and cumulative quality credits.
- Students may use `[approved student-provided record, such as an unofficial transcript]` when permitted.

When reading a report or transcript, verify that the cumulative GPA and cumulative quality credits belong to the same reporting point. Do not use a current-term or incomplete-term value as the baseline unless the user explicitly requests that scenario and the source supports it.

If the source does not clearly identify cumulative quality credits, ask the user to provide the exact value rather than substituting total attempted credits, earned credits, or another nearby field.
